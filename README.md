# E-Commerce Management System

## Project Overview

This project is a relational database management system built using PostgreSQL. It represents an e-commerce platform and manages customers, products, suppliers, orders, payments, shipments, and other business operations.

## Technologies Used

- PostgreSQL
- SQL
- pgAdmin 4

## Database Tables

The database contains 14 tables:

1. Customers
2. Addresses
3. Categories
4. Suppliers
5. Products
6. Orders
7. Order Items
8. Payments
9. Shipments
10. Reviews
11. Wishlist
12. Cart
13. Cart Items
14. Employees
